# Bounded Wang reconstruction resolves the captured Gluza33 factor

An isolated Symbolica experiment factors the original 2,410-term Gluza33
operand in **1.04 seconds**, with exact signed reconstruction. The same
executable with the experiment disabled times out after 60 seconds. This
resolves one captured algebraic obstruction; it does **not** establish a
complete Gluza33 decomposition or a benchmark-suite speedup.

The [preceding profile](GLUZA33_FACTOR_PROFILE.md) found a cheap factorization
of the 25-term leading coefficient, but only necessary specialization gates
had been checked. The new experiment successfully completes the bivariate
factorization, leading-factor assignment and final factorization. Its policy
uses polynomial features and a bounded prime schedule, with no problem names,
hash dispatch or changes to CAD coordinates/interior boundaries.

## Matched bounded measurement

Both trials use the same frozen debug profiler, Symbolica at dependency
opt-level 2, the same captured polynomial/full variable map, CPU 14, one worker,
4 GiB and 60 seconds. Only the experiment's environment flag changes. Diagnostic
tracing is enabled in both, so these timings are outside solver benchmarks.
This is one run per setting, not a median performance estimate.

| Setting | Algebra time | Worker wall time | Peak RSS | Result |
|---|---:|---:|---:|---|
| Bounded small-LC Wang path enabled | 1.039306 s | 1.096001 s | 14,256 KiB | Exact product reconstructed |
| Same executable, path disabled | — | 60.033840 s | 14,508 KiB | Timeout |
| Separate native factor export | 1.054112 s | 1.094600 s | 13,864 KiB | Full factors exported and replayed |

The export contains **two factors, 106 and 821 terms, both multiplicity 1**,
with full map `[x2,x1,x7,x4,x6,x3,x5]`. Independent signed product replay takes
0.004421 s. The exported expressions, multiplicities and scalar signs remain
in the ignored artifact; nothing was manually inserted into a production cache.

The enabled trace rejects `(x1,x7)=(3,7)` and `(7,3)` through the existing image
gates, then accepts the complete leading assignment at `(11,13)`. The disabled
trace directly records **364 entries to `find_sample`, 1,090 bivariate factor
starts and 1,089 completions**, each reporting 2,410 source terms and 25 leading
terms. The trace binds those shapes and the variable order, not a full polynomial
hash per entry; identical polynomial contents across those recursive entries
are therefore not established by the trace. These events provide direct
evidence of repeated sampling/reconstruction beyond the earlier truncated
perf stacks. The last bivariate call is interrupted. Logging itself adds
overhead; no exact speedup ratio is claimed.

## General algorithm and correctness obligations

The [algorithm patch](../patches/experimental/symbolica-bounded-small-lc-wang.patch)
is optional and is not applied to the main dependency. It extends only the
admission and candidate selection for Symbolica's existing Wang first-image
reconstruction. The historical monomial-LC path is preserved.

Additional admission requires three active variables, at most 8,192 source
terms and degree 32 per active variable; a nonmonomial leading coefficient of
2–128 terms, at most two active variables, degree 32 and 8,192-bit coefficients.
Existing density and evaluated-degree gates remain. Leading factorization
is followed by exact signed product replay with full variable maps, all
multiplicities and finite reconstruction-work bounds.

The schedule generates six disjoint consecutive prime pairs, each in both
orders, skipping divisors of the leading coefficient's integer content.
It inspects at most 64 primes and proposes at most 12 tuples. The successful
point is generated by this rule; it is not hardcoded. All existing nonzero,
pairwise-coprimality, degree-preservation, squarefreeness, primitive-content,
factor-assignment and exact signed leading-product checks remain unchanged.
Failure or exhaustion preserves the existing fallback.

A specialization alone never establishes factorization or irreducibility.
The established backend requires its separable-content/squarefree preprocessing
and subsequent exact lifting/reconstruction. The outer research profiler
additionally replays the complete signed source product before accepting a
result. This change creates no domain reduction and removes no singular seam.

## Tests and upstream scope

Nineteen selected backend tests pass: 16 Wang tests and three existing bivariate
sampling controls. Five new regressions cover signed nonmonomial reconstruction,
parameter-only content through public `factor()`, a first specialization where
two factors coincide, bounded exhaustion followed by fallback, and an empty
finite prime menu. An independent read-only review found no mathematical
blocker. This evidence supports an optional experimental backend candidate;
broader factorization-corpus measurements remain necessary before a default
upstream policy change.

The isolated test build exposed unrelated evaluator tests importing native/JIT
APIs when that feature is disabled. The separate
[test-harness patch](../patches/experimental/symbolica-factor-tests-without-native-codegen.patch)
gates only that unselected test module on its required feature. It affects no
normal library code and removes none of the selected factor tests. Preserve
it separately from the algorithm patch when proposing an upstream change.

## Reproduction and provenance

Both patches apply to Symbolica
`75f8350094b90254ee71dc2a391fde0d14b0204a`, without optional root-isolation
patches. Apply them only to an isolated checkout. Point an isolated copy of the
symGCAD manifest at it, retain the pinned local `numerica`/`graphica` patches,
and add Symbolica feature `research_small_lcoeff_wang`. Use a separate Cargo
target directory. The algorithm also requires environment flag
`SYMBOLICA_RESEARCH_SMALL_LC_WANG=1`; leaving it absent selects the control.
`SYMBOLICA_RESEARCH_WANG_TRACE=1` enables diagnostic stage events.

```sh
export SYMBOLICA_RESEARCH_SMALL_LC_WANG=1
cargo --config profile.test.package.symbolica.opt-level=0 \
  --config profile.test.package.symbolica.debug=0 \
  test --locked --manifest-path ISOLATED/Cargo.toml \
  -j2 -p symbolica --lib wang -- --test-threads=1
cargo --config profile.dev.package.symgcad.debug=0 \
  build --locked --manifest-path ISOLATED/Cargo.toml \
  -j2 --example profile_operation --example profile_affine_factorization
```

Use `profile_operation CAPTURE --factor-start auto --seconds 60 --memory-mib
4096 --output FRESH.json` under `taskset -c 14`. The existing affine profiler's
`--mode native --seconds 30 --cpu 14` exports full factors and independently
replays their product; supply the capture SHA-256 and a fresh output directory.
Do not interpret the helper's name as a coordinate transformation in native mode.

Artifacts are under `artifacts/research/gluza33-wang-isolated-01/`, including
frozen binaries, failed and successful build logs, full traces, native export,
patches and checksums. An original warm Gluza33 continuation is kept separately
under `gluza33-wang-production-01/`, with unchanged input/order/solver flags,
16,537 inherited operation records, a 600-second solve limit and 50 GiB.
It **timed out after 600.096463 s**, at 780,840 KiB peak RSS, with no result or
verification. It completed the old factor key `5b9185fc…` in 8.679598 s for the
full solver operation (including its preprocessing), and retained **202 new
operations**, for 16,739 total. The final obstruction is again the earlier
19,942-term degree-24 discriminant `4fa9b805…`, with the same full input hash
`eba809f2…`. The last progress record, at 176.85 s, reports prefix `[2,2/3]`;
it is stale and is not the duration of the pending call. No complete generic
decomposition is claimed. The factor improvement is established; the next
projection obstruction remains unresolved.
